# Code of conduct

conductor-ai should be a friendly place to ask questions and send changes, whatever your experience.

**Please:**
- Be kind and patient, especially with people who are new.
- Assume good intent. Ask before you assume.
- Criticise code and ideas, never people.
- Keep discussions on topic and easy to follow.

**Not okay:**
- Harassment, insults or personal attacks.
- Discriminatory jokes or language.
- Publishing someone's private information.
- Repeatedly pushing a point after you've been asked to stop.

The maintainer may edit or remove comments, issues and PRs that break these rules, and may block people who keep breaking them. To report a problem privately, use the contact on [the maintainer's GitHub profile](https://github.com/KevalParikh22) or the private channel in [SECURITY.md](SECURITY.md).

This code is based on the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/).
